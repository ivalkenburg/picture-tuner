# Prepare Picture Tuner assets from Luma Dial

Use this source kit to produce and integrate usable assets for the Android TV application Picture Tuner. The user selected **Luma Dial**. Use the Luma Dial sources throughout this task.

1. Inspect `previews/source-sheet.png`, then read `brand.json` for the palette and geometry. Use `svg/mark.svg` as the symbol authority and the outlined logo SVGs as the lettering authority. `reference/concept.png` records the initial Luma Dial proposal only.
2. Inspect the destination application's manifest, resource folders, minimum SDK, themes, and build setup. Decide the required launcher, adaptive icon, TV banner, monochrome, and store exports from the destination's actual needs and current platform requirements. These SVG templates are source compositions, not an installed Android resource set.
3. Convert SVG geometry to the destination's supported vector or raster resources. For Android VectorDrawable conversion, bake group transforms into path coordinates or convert them correctly to Android groups. The mark contains three closed filled paths with rounded ends already outlined. Preserve the open ring and its transparent interior around the opaque center square. The background is a separate solid charcoal layer.
4. Preserve the symbol's proportions, upper-right gap, diagonal tick, rounded square, flat palette, and wordmark spelling and letter shapes. Scale and reposition for output constraints. Use the mark alone for square icons and the wordmark composition for TV banners. Let the platform apply icon masks; the square and background sources have full-bleed rectangular bounds. The tick extends radially beyond the ring, so keep the entire foreground inside the target platform's safe region and verify cropping under its masks. The provided foreground leaves extra room for this tick.
5. Validate exported sizes, transparent regions, lettering at launcher size, and icon masks. Compare converted vectors visually against the SVG sources, then build the app and verify manifest references resolve. Report produced paths and checks, including hardware validation that could not be run.

The source kit does not change the application's installed resources. Preserve the canonical source files alongside generated resources for future exports. If editing the lettering, install the bundled Nunito Sans font, use weight 800, and create fresh outlines; the editable wordmark depends on that font.
